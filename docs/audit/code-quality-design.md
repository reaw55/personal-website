# Code Quality, Maintainability & UI-Consistency Audit

Scope: `personal-website/` (React 18 + Vite 8 + Tailwind 3), reviewed after the fixes in `docs/HANDOFF.md`.
Files read: `src/App.jsx`, `src/main.jsx`, `src/index.css`, every file in `src/components/*.jsx`, `tailwind.config.js`, `eslint.config.js`, `package.json`.

## Summary

The code is small and readable, and `npx eslint .` reports **0 problems**. The main maintainability risks are:

1. **Navbar.jsx works around React instead of through it.** It adds and removes classes and sets inline styles on DOM nodes directly. Its scroll handler also queries the DOM on every scroll event.
2. **The same content is defined in several places.** The section list appears twice and the social links appear twice. `certsList.jsx` repeats the same inline-style object 30 times.
3. **Names and props are inconsistent.** Examples are the `imcSrc` prop, `Cousera`, the `protait` folder and numbered props like `awardLink1/2`.
4. **There are no design tokens.** Colours, radii, ring widths and sub-heading styles are hard-coded per component and differ between components that look alike.
5. **There are no tests, no CI and no type checking**, apart from PropTypes.

## Verified OK

- `npx eslint .` reports 0 errors and 0 warnings.
- The rules from `react-hooks` (both rules of hooks and exhaustive-deps) and `react/jsx-no-target-blank` are enabled.
- Every link with `target="_blank"` also has `rel="noopener noreferrer"`. `Button.jsx` adds it automatically.
- `App.jsx` uses `useGSAP` with `gsap.matchMedia()` and cleans up with `mm.revert()`. Reduced motion is handled in both JS and CSS (`App.jsx:24-66`, `index.css:107-116`).
- The `useEffect` listeners in Navbar remove themselves on cleanup, and the scroll listener is `passive` (`Navbar.jsx:61-63, 128-134`).
- `Button.jsx` is a clean shared renderer: it renders `<a>` when given an `href` and `<button>` otherwise, and its `target` defaults to `_self`.
- `About.jsx` handles link hover and focus colours in CSS through custom properties, with no JS mouse handlers.
- Every component declares PropTypes, and `prop-types` is listed in `package.json`.
- The Header menu button has `aria-expanded`, `aria-controls` and a label that changes with its state. The mobile menu closes after a link is tapped (`onNavigate`).
- `StrictMode` is enabled (`main.jsx:8`). `package.json` declares Node 20.19 or later in `engines`.
